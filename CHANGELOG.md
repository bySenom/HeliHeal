# HeliHeal 0.9.7 Beta 1

## Changes

- Long hotkey labels now expand icon spacing automatically and no longer overlap.
- Cached abilities and reusable HUD tables significantly reduce ongoing memory growth.
- Nature's Swiftness and Ancestral Swiftness now disappear immediately after a confirmed successful cast.
- Unleash Life is confirmed directly from the player's successful cast.
- Consumed random Stormstream procs no longer spend a regular Healing Stream Totem charge.

## Validation

- All automated Lua tests passed.
- The packaged addon contains only supported runtime files and documentation.
- This is a beta release intended for in-game testing and feedback.
