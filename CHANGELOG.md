# HeliHeal 0.9.8 Beta 1

For **World of Warcraft: Midnight 12.1**.

## Changes

- Added independent width, height, zoom and position controls for primary and secondary icons.
- Added separate position and size controls for hotkeys, cooldowns, role labels, priority badges, ability names and the header.
- Added individual colors for the panel, panel border, icon background, hotkey background and HUD text elements.
- Added talent-aware Beacon of Virtue support to Holy Paladin Mythic+ Standard and AoE modes with a confirmed 15-second cooldown.
- Existing profiles migrate automatically while retaining their previous appearance.
- CurseForge and GitHub now use curated Markdown release notes without Git author metadata.

## Validation

- All automated Lua tests passed.
- The version tag matches `HeliHeal.toc`.
- The packaged addon contains only runtime files and documentation.
- This is a beta release intended for in-game testing and feedback.
